# LogiFlow Documentation

## Project Overview

LogiFlow is a full-stack logistics and courier delivery management
platform.

The application provides:

- Shipment creation and management
- Real-time shipment tracking
- Delivery status management
- Customer authentication
- Customer dashboard
- Warehouse workflow
- Interactive 3D logistics scenes
- Responsive professional UI/UX
